# Yinsong Yan — Personal Homepage

A lightweight, single-page academic homepage inspired by the clean, text-first structure of [Zixiang Zhao's homepage](https://zhaozixiang1228.github.io/), with a custom visual direction for Yinsong Yan.

## Run locally

This site has no build step. Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
